ISSUES ENCOUNTERED & RESOLVED
------------------------------------------------------------------------

Issue 1 : Alembic "No module named 'app'" error
          alembic upgrade head / bash -c "cd /app && alembic upgrade head" both failed
Fix     : Use python -m alembic instead of alembic directly
          Command: sudo docker-compose exec api bash -c "cd /app && python -m alembic upgrade head"
          When using -m, Python adds current directory to sys.path automatically

Issue 2 : First alembic run showed no migration applied
Cause   : EC2 had old code — migration file didn't exist yet
Fix     : git pull first, rebuild container, then run migration

Issue 3 : Port 8000 not reachable from browser (ERR_CONNECTION_TIMED_OUT)
Cause   : AWS Security Group had no inbound rule for port 8000
Fix     : Added Custom TCP inbound rule: port 8000, source 0.0.0.0/0 in AWS Console
          Corporate network workaround: SSH tunnel
          ssh -i "C:\Claude\Project-GSR\g2r-poc.pem" -L 8080:localhost:8000 -N ec2-user@43.204.43.71
          Then open http://localhost:8080/docs (tunnels through SSH port 22)

Issue 4 : Two builds triggered (Build #2 master + Build #3 main)
Cause   : Push to master then master:main sync both triggered the workflow
          (workflow triggers on both branches when gsr_app/** changes)
Resolution: Expected behavior — both are the same code (commit c79fb60). Use #3 (latest).
