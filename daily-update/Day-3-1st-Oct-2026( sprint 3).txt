ISSUES ENCOUNTERED & RESOLVED
------------------------------------------------------------------------

Issue 1 : Swagger "Authorize" button not sending Bearer token
          curl showed no Authorization header even after clicking Authorize
Fix     : Page needed a refresh after authorizing. After refresh, the per-endpoint
          lock icon worked. Used PowerShell Invoke-RestMethod as fallback for
          confirm-totp and verify flows (faster + reliable)

Issue 2 : bcrypt version warning on passlib startup
          "(trapped) error reading bcrypt version — module 'bcrypt' has no __about__"
Fix     : Harmless — bcrypt >= 4.0 removed the __about__ module. passlib still
          works correctly for hashing. Not a blocker.

Issue 3 : TOTP code expires in 30 seconds
Fix     : Used PowerShell (faster than Swagger forms) to hit confirm-totp
          before the code expired. If expired: just use the next code from app.
